# ビスケット 背景カラーダイアル

ビスケットの背景グラデーションを、上側・下側それぞれの色を選んで作る非公式のWebツールです。

## 使い方

1. 上側・下側のダイアルを回して色相を選びます。
2. 丸い色パレット、または「鮮やかさ」「明るさ」で色を調整します。
3. 中央のRGB値と、右側の背景プレビューを確認します。
4. 「JSONをコピー」で、作品JSONの `bg` に設定する値をコピーします。

RGBの各値を直接入力することもできます。ダイアルはキーボードの矢印キーでも操作でき、Shiftを押しながらだと大きく変化します。

- 上下の色の入れ替え
- 配色プリセット
- 既存の `bg` または作品JSONからの背景色の読み込み
- ブラウザ内での前回の配色の保存
- スマートフォン・タブレットへの対応

作品JSONを読み込んでも、そのファイル自体は書き換えません。生成した `bg` の断片を手動で置き換えてください。

## 色の数値

`bg` の先頭が上側、2番目が下側です。各色を次の式で整数に変換します。

```text
色の整数値 = R × 65536 + G × 256 + B
```

例えば、ピンクから淡い黄色の背景は次の値になります。

```json
"bg": [16756684, 16773540]
```

- 上側：RGB(255, 175, 204) / #FFAFCC
- 下側：RGB(255, 241, 164) / #FFF1A4

提供された背景画像とJSONの組み合わせに基づく変換です。ビスケット公式の仕様書に基づくものではありません。

## ローカルで使う

`index.html` を保存してブラウザで開くだけで使えます。インストールやビルドは不要です。色の操作とJSON変換はブラウザ内で行います。

クリップボードへのコピーをブラウザが許可しない場合は、選択されたJSONを手動でコピーしてください。

## GitHub Pages

リポジトリの **Settings → Pages** で、次のように設定します。

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

## このツールについて

ビスケットの背景色を作るための補助ツールです。ビスケットの公式アプリではなく、ビスケットへの自動反映機能はありません。
